# AI教学知识库 · 学生端

> 面向酒店管理专业的 AI 智能学习训练平台 —— 移动端单页应用

基于原生 HTML/CSS/JavaScript 构建的酒店管理专业学生端学习应用，集成课程学习、答题练习、三维导师智能问答、AI 角色扮演训练、学情报告与招聘推荐等功能，为学生提供从知识学习到技能训练到职业发展的全链路学习体验。

## 功能架构

### 🏠 首页
- 个性化问候与用户信息展示
- AI 角色训练每日推荐（Banner 入口）
- 四宫格快捷入口：我的课程 / 答题练习 / 智能问答 / 角色训练
- 继续学习横向滑动卡片（显示学习进度）
- 推荐课程卡片（含薄弱点标记、热门标签）

### 📚 课程中心
- 六大课程分类筛选：前厅管理 / 客房管理 / 餐饮运营 / 宴会管理
- 课程卡片：知识点数 · 案例数 · 题目数 · 学习进度
- **课程详情**：章节目录 + 课时列表（已完成 / 进行中 / 未解锁三级状态）
- **知识单元学习**：四步教学法
  - ① 情景导入（视频 + 思考问题）
  - ② 知识讲解（分步知识卡片）
  - ③ 互动练习（选择题 + 即时反馈）
  - ④ 总结反馈（得分 + 核心要点回顾）

### ✏️ 答题练习
- 学习数据看板：总答题数 / 正确率 / 连续学习天数
- 薄弱知识点智能预警
- 今日推荐练习（基于薄弱点智能推送）
- 六大课程分类题库（含进度条）
- **答题进行中**：计时器 + 进度条 + 单选题 + 答案反馈 + 相关知识点
- **答题结果**：总分 + 各维度评分 + 薄弱点推荐

### 🤖 智能问答
- 热门问题排行榜（1-5名带排名样式）
- 最近提问历史
- **三维导师回答**：
  - 🎓 学术导师 —— 理论体系 · 学术规范
  - 💼 企业导师 —— 行业实践 · 操作规范
  - 🎯 职业规划导师 —— 职业发展 · 求职建议
- 相关知识点链接
- AI 对话追问（聊天气泡式交互）

### 🎭 AI 角色训练
- 四大岗位角色：前台服务员 / 客房服务员 / 餐厅服务员 / 大堂经理（渐进解锁）
- 五大训练场景（按难度分级）：
  - ⭐⭐ 基础：高峰期标准入住接待
  - ⭐⭐⭐ 进阶：处理挑剔商务客人 / 家庭客人特殊需求
  - ⭐⭐⭐⭐ 困难：外籍客人英语接待
  - ⭐⭐⭐⭐⭐ 挑战：投诉型客人危机处理
- **训练进行中**：AI 扮演客人对话 + 场景提示 + 语音输入
- **训练结果**：
  - 五维评分：语言表达 / 服务规范 / 问题处理 / 反应速度 / 客户满意度
  - AI 专业点评 + 改进建议
  - 成就系统（如"首次满分客户满意度"）

### 👤 个人中心
- 学习统计：完成课程 / 平均正确率 / 角色训练 / 连续学习
- **学情报告**：成绩趋势 + 各课程掌握情况 + 薄弱点强化
- **招聘推荐**：基于学习数据智能匹配岗位（匹配度 + 薪资 + 标签）
- 成就系统：学习达人 / 高分获得者 / 训练达人 / 全科优秀
- 设置菜单：消息通知 / 学习偏好 / 账户安全 / 联系客服

## 快速开始

### 本地运行

直接在浏览器中打开 `index.html` 即可：

```bash

open index.html

# 方式二：本地服务器
npx serve .
```

## 项目结构

```
hotel-training-app/
├── index.html    # 完整单文件应用（HTML + CSS + JS）
└── README.md     # 项目说明
```

所有代码集中在 `index.html` 一个文件中（~1440行），包含：

- **CSS 变量系统**：10+ 主题变量（primary/accent/success/warn/danger/bg/card/text/shadow/radius）
- **30+ 自定义组件样式**：卡片、按钮、标签、进度条、聊天气泡、选项卡、步骤条等
- **12 个页面视图**：首页、课程列表、课程详情、知识学习、答题首页、答题进行、答题结果、智能问答、问答详情、问答对话、角色训练、训练结果
- **交互系统**：页面转场动画、Toast 提示、确认对话框、Tab 切换、步进切换

## 设计规范

- **主色调**：`#4A7CF7`（蓝紫渐变）+ `#5B5EF8`（辅助紫色）
- **语义色**：Success `#22c55e` / Warn `#f97316` / Danger `#ef4444`
- **圆角**：16px 卡片 / 12px 按钮 / 8px 小元素 / 24px 全宽按钮
- **阴影**：sm(2px) / md(4px) / lg(8px) 三级
- **动效**：fadeInUp / scaleIn / pulse / slide 转场
- **布局**：390×844 手机仿真框 + 刘海装饰 + 底部毛玻璃 Tab 栏

| 功能 | 教师端 | 学生端 |
|------|--------|--------|
| 课程管理 | 创建/管理课程与教学计划 | 浏览课程、按章节学习 |
| 知识库 | 上传/管理教学资源 | 学习知识内容 |
| AI 备课 | 生成课件、设计测验 | 接收并学习课件 |
| 任务分发 | 配置分发对象与防作弊规则 | 完成练习与测验 |
| 学情分析 | 查看全班学情雷达图/柱状图 | 查看个人学情报告/薄弱点 |
| AI 问答 | AI 教学助手（单维度） | 三维导师（学术/企业/职业） |
| 角色训练 | — | AI 对话式角色扮演训练 |
